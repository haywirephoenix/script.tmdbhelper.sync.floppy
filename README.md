# TMDbHelper Sync - Floppy (Installer)

Installs [TMDbHelper Sync - Floppy](https://github.com/haywirephoenix/script.module.tmdbhelper.sync.floppy),
the Floppy sync provider for TMDbHelper. That provider is a module (TMDbHelper finds it by its id,
`script.module.tmdbhelper.sync.floppy`), and Kodi's repository browser doesn't list modules, so
this small add-on is what you install from [repository.haywire](https://github.com/haywirephoenix/repository.haywire):
Kodi brings the module, and TMDbHelper, with it.

Open it (Program add-ons) to set the sync up:

1. **Set up Floppy sync**: your Floppy address and API token, or leave them empty to use the
   Floppy add-on's.
2. **TMDbHelper settings**: choose Floppy for history and progress, watchlist and scrobbling.

Published to repository.haywire on a version bump (`.github/workflows/publish.yml`).
